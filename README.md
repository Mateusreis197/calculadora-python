# 🧮 Calculadora Python

Calculadora em linha de comando desenvolvida em Python, criada na Imersão Engenharia de Software: Dev na Era da IA (Alura + Google).

---

## 📌 Sobre o Projeto

A calculadora faz as quatro operações básicas e o cálculo de porcentagem:
- **Adição, subtração, multiplicação e divisão**, com tratamento de divisão por zero.
- **Porcentagem (X% de Y):** por exemplo, 20% de 150 = 30.

O projeto foi feito em duas etapas da imersão:
- **Desafio 1:** versão básica criada no Google AI Studio.
- **Desafio 2:** evolução com a operação de porcentagem (commit `cd3ca61`).

---

## 🚀 Tecnologias Utilizadas

- **Linguagem:** Python
- **Bibliotecas:** `python-dotenv` (leitura de variáveis de ambiente)

---

## ⚙️ Instalação

```bash
pip install python-dotenv
```

---

## 💻 Como Executar

```bash
python calculadora_python.py
```

Escolha a operação no menu e digite os números pedidos.
